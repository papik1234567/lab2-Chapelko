## 1. Цель работы

Разработать три независимых программных модуля, реализовать их интеграцию в единую систему и проверить работоспособность полученного решения.

## 2. Исходные данные варианта

Необходимо выбрать антивирусное решение для организации, в которой используется 50 рабочих станций и требуется централизованное управление.

Рассматриваемые альтернативы:
- Kaspersky Endpoint Security;
- ESET NOD32;
- Dr.Web.

## 3. Структура проекта

- `chapter1.sh` — модуль выбора технологического решения.
- `chapter2.sh` — модуль формализации ревью кода.
- `chapter3.sh` — модуль сравнительного анализа WSM.
- `lab_system.sh` — интеграция программных модулей.
- `report.txt` — итоговый отчёт о выполнении модулей.

## 4. Модуль 1. Выбор технологического решения

Модуль задаёт вопросы о масштабе проекта, бюджете, сроках реализации и квалификации команды.

На основании введённых данных формируется рекомендация по выбору антивирусного решения.

## 5. Модуль 2. Формализация ревью кода

Модуль предлагает проанализировать пять фрагментов кода и определить тип дефекта.

Рассматриваемые типы дефектов:
1. Неинициализированная переменная.
2. Мёртвое присваивание.
3. Утечка ресурса.
4. Магическое число.
5. Отсутствие обработки ошибок.

По результатам анализа рассчитываются количество правильных ответов, процент точности, баллы и уровень ревьюера.

## 6. Модуль 3. Сравнительный анализ WSM

Для сравнения антивирусных решений используются четыре критерия:
- централизованное управление;
- уровень защиты;
- стоимость владения;
- удобство администрирования.

Пользователь задаёт веса критериев с общей суммой 100 и оценивает каждую альтернативу по шкале от 1 до 5.

Итоговый показатель рассчитывается по формуле:

`S = Σ(W × X)`

По полученным результатам определяется наиболее подходящее решение.

## 7. Интеграция модулей

Файл `lab_system.sh` предоставляет единое меню для запуска каждого модуля отдельно или всех модулей последовательно.

При выборе четвёртого пункта меню запускаются все три модуля. Их вывод сохраняется в файл `report.txt`.

## 8. Инструкция по запуску

Для запуска проекта на macOS необходимо открыть терминал в каталоге проекта и выполнить:

```bash
./chapter1.sh
./chapter2.sh
./chapter3.sh
```

## 9. Проверка работоспособности

В ходе тестирования проверены:
- запуск каждого модуля отдельно;
- обработка пользовательского ввода;
- расчёт результатов модулей;
- определение победителя сравнительного анализа;
- последовательный запуск всех модулей;
- формирование файла `report.txt`.
